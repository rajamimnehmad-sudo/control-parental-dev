# Historial de rendimiento DAG

Matriz permanente para cada candidato o version que cambie navegador, WebView, carga o imagenes:

- Fravega: `https://www.fravega.com/`
- Mimo: `https://www.mimo.com.ar/`
- Cheeky: `https://www.cheeky.com.ar/`

Cada recorrido guarda tres metricas `DagPerformance`: `page_analysis_ready` es `GeckoSession.onPageStop` para pagina/texto, `viewport_images_ready` es el trabajo visual de la ventana inicial acotada ya quieto y `page_visible` es la estructura protegida utilizable aunque queden fotos pendientes. Usa `codexperf`, conserva el mismo dispositivo y registra timeouts o roturas como regresiones. DAG Browser V3 usa GeckoView, no `LOAD_NO_CACHE` de WebView; el fixture controlado precede a sitios vivos y cada evidencia declara perfil/cache, frio/caliente y cantidad de muestras.
